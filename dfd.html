Data Flow Guide

This Data Flow Diagram (DFD) illustrates how information moves through the QRead system.

💡 Gestures

  • Pan: Click/Touch and drag to move the canvas.
  • Zoom: Pinch with two fingers or use mouse wheel.

📊 Key Components

  • Actors (Blue): Users interacting with the system (Students, Admins).
  • Processes (Green): Actions transforming data (e.g., Issue Book, Auth).
  • Stores (Orange): Databases where data rests (e.g., D1 User).

🔄 Flow Example

A Student initiates an Issue Request (P3). This process checks Book Availability (D2) and creates a Record (D3).
